# Student Performance Analysis and Score Prediction

## Project Overview

This project analyzes factors that affect student academic performance and predicts exam scores using Machine Learning.

## Objectives

* Clean and preprocess student data
* Handle missing values
* Encode categorical features
* Analyze relationships between variables
* Predict exam scores using Linear Regression
* Identify factors that influence performance

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn

## Project Files

* analysis.py — Main project code
* data.csv — Dataset
* feature_importance.csv — Feature impact analysis
* sample_predictions.csv — Actual vs predicted scores
* README.md — Project documentation

## Machine Learning Model

Linear Regression

## Workflow

1. Load dataset
2. Clean data
3. Handle missing values
4. Encode categorical variables
5. Train machine learning model
6. Evaluate model performance
7. Generate predictions

## Output

The project generates:

* Feature importance analysis
* Sample score predictions
* Model evaluation metrics

## How to Run

Install dependencies:

pip install pandas numpy scikit-learn

Run the project:

python analysis.py
